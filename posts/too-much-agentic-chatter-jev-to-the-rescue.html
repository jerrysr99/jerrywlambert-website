Too Much Agentic Chatter? Jev to the rescue!

October 23, 2026

My agents were burning frontier tokens to say "got it" to each other.

I run a crew of AI agents. Each one has a job, and they message each other to hand off work. Every message wakes a frontier model. Every "thanks," every "still working on it," every FYI costs the same as real work. That chatter adds up fast, and none of it moves the job forward.

So I put Jev in front of the conversation.

Jev is a small classifier. Before an agent sends a message, it answers one question: does the recipient need to act on this now? If yes, the message goes out and wakes the recipient. If it is an FYI, it either goes to a log file or waits quietly without waking anyone. Nobody gets woken up for a thank you or a status update.

Jev gives a plain yes or no. It runs through my proxy, answers in about 0.4 seconds, and costs $0.042 per million input tokens. Output is free. The frontier model only wakes up when there is work to do.

Here is what it does to you.

If you are paying frontier prices for every message between agents, you are paying for meetings that should have been emails. Most handoffs are routing decisions, and routing decisions do not need a frontier model. Put a cheap gate in front, meter every call, and let the expensive model think only when thinking is the job.

Cut the chatter before you cut the agents.
