Daily Model Brief, November 19, 2026

Google launched Gemini 4 Neon at $3.00 input and $15.00 output per million tokens, between today's Gemini 4 Argon price and the price Argon moves to on December 1. Perplexity priced two new contextualized embedding models, and OpenAI set January 11, 2027 to end Fast and Priority processing for EU data residency on GPT-5.2 and GPT-5.4.

Executive Summary

Google released Gemini 4 Neon (gemini-4-neon) as generally available on Wednesday. It lists at $3.00 input, $0.15 cached and $15.00 output per million tokens, 50% above Gemini 4 Argon and Gemini 4 Carbon at today's $2.00, $0.10 and $10.00, and 25% below the $4.00, $0.20 and $20.00 they move to on Tuesday, December 1. Output includes thinking tokens, one price covers the full 1M-token context window, and long decode allows up to 1M output tokens. It is paid tier only.

Gemini 4 Neon's Batch and Flex prices are half of Standard ($1.50 input, $0.075 cached and $7.50 output), and Priority costs 1.8 times Standard ($5.40, $0.27 and $27.00). Caching is implicit only, and Google Search grounding uses the same terms as other Gemini 3 and newer models: 5,000 free searches a month, then $14 per 1,000.

Perplexity released two contextualized embedding models. pplx-embed-v2-context-9b costs $0.12 per million text tokens and $0.42 per million image tokens, and pplx-embed-v2-context-0.6b costs $0.02 and $0.40. Its Context API can now also score pages against your criteria, billed as Decisions API input tokens on top of the $0.001 per URL price; requests without criteria still have no token billing.

OpenAI deprecated Fast and Priority processing for GPT-5.2, GPT-5.4 and GPT-5.4 mini with EU data residency on Wednesday, with shutdown on Monday, January 11, 2027. The named replacements are the same models with EU data residency on Standard processing, or the GPT-6.2 models.

Microsoft retires o1, o1-pro, o3, o3-pro, o3-deep-research, o3-mini and o4-mini on Azure today, along with Llama 4 Maverick. Its retirement table, updated Wednesday, names gpt-5.6-sol or gpt-5.6-terra as replacements where offered, and gpt-5.4 or gpt-5.4-mini for Global and US Data Zone Batch deployments. These Azure dates do not change OpenAI's own API dates.

DeepSeek clarified its search billing change: the server-side search and fetch calls themselves are free, and the results they return are added to the model's context and billed as model tokens.

No vendor I track changed a standard list token price on an existing publicly available text or chat model since Wednesday's brief.

What This Means for Customers

  • If you plan Gemini 4 Argon or Carbon spend past December 1, price gemini-4-neon alongside them. Neon's $3.00 input and $15.00 output sit below the $4.00 and $20.00 Argon and Carbon move to that day. Output includes thinking tokens on all three, so compare cost per task, not per token.
  • If you run GPT-5.2, GPT-5.4 or GPT-5.4 mini with EU data residency on Fast or Priority processing, move that traffic to Standard processing or to a GPT-6.2 model before Monday, January 11, 2027.
  • If you still have o1, o3 or o4-mini deployments on Azure, they retire today. Microsoft points Standard deployments to gpt-5.6-sol or gpt-5.6-terra, and Batch deployments, where those are not offered, to gpt-5.4 or gpt-5.4-mini.
  • If you embed chunked documents or page images, Perplexity's pplx-embed-v2-context-0.6b costs $0.02 per million text tokens and pplx-embed-v2-context-9b $0.12. Requests must set input_type to query or document, or they return an HTTP 400 error.
  • If you run gpt-6-astra, test gpt-6.2-astra. It lists 20% lower on input and output and 60% lower on cached input, but OpenAI changed how GPT-6.2 handles reasoning on edited conversations and the instructions field, so check your integration before you switch.
  • If you run gpt-6.1-sol, gpt-6.2-sol costs the same on Standard, Batch and Fast. If you depend on Flex, keep that work on a model that has a Flex price; OpenAI lists none for GPT-6.2.
  • If you plan to use Ultrafast on GPT-6.2, budget for March 1, 2027. The rate goes from three times Standard to six times, which doubles the Ultrafast bill for the same work.
  • If your OpenAI jobs can wait two to eight hours, test the background completion windows in the Responses API. Token rates are 30% lower for the two-hour window and 40% lower for the eight-hour window on GPT-6.2 Astra, GPT-6.2 Sol, GPT-6.1 Terra and GPT-6 Luna.
  • If your deepseek-flash traffic uses DeepSeek's web tools or a web_search tool, searches the model runs no longer add $0.75 per 1,000 on top of tokens. Calls you make straight to the Search or Fetch API still do. The results those searches return still count as model tokens.
  • If you fetch known URLs through Perplexity, its Context API bills $0.001 per URL that comes back, and failed URLs are free. Adding scoring criteria adds Decisions API input tokens for each scored page.
  • If you run large offline qwen4-max jobs in Alibaba's China (Beijing) region, Batch File halves the cost to $0.707 input and $2.12 output per million tokens. Alibaba lists no batch price for International (Singapore).
  • If you run qwen3.8-max in Alibaba's International region, test qwen4-max. It lists 25% lower on input and output ($1.50 and $4.50 against $2.00 and $6.00), and the saving only applies once you change the model string.
  • If you build on StepFun's StepAudio 3 voice models, the free period now ends at 10:00 PM CT on Sunday, November 22. Realtime speech then bills at $0.125 per session minute, counted by the second, and text to speech at $14.00 per million input characters.
  • If you run Claude Opus 4.5 or Claude Haiku 4.5 on Microsoft Foundry, plan the move to claude-opus-5-5 or claude-haiku-5-5 before Monday, February 22, 2027.
  • If you run gemini-3.8-flash for coding or agent work, test gemini-4-hydrogen. Its $1.50 input and $7.50 output are double 3.8 Flash's $0.75 and $3.75 through December 31, but match the price 3.8 Flash moves to on January 1, 2027. Hydrogen's output price includes thinking tokens, so compare cost per task, not per token.
  • If you still call gpt-5, gpt-5-mini, gpt-5-nano or o3, test gpt-6.1-sol, gpt-6.1-terra and gpt-6-luna before Friday, December 11.
  • If you budget for either Gemini 4 model, plan for December 1. Input, cached and output prices all double that day, from $2.00, $0.10 and $10.00 to $4.00, $0.20 and $20.00 per million tokens.
  • If you call gemini-2.5-pro, test gemini-3.8-flash before Tuesday, December 1. At today's list prices the routed requests cost less per token ($0.75 input and $3.75 output through December 31, against 2.5 Pro's $1.25 and $10.00 for prompts up to 200K tokens), but 3.8 Flash rises to $1.50 and $7.50 on January 1, 2027.
  • If you call gemini-2.5-flash, requests move to gemini-3.5-flash-lite on December 1 at the same text list price ($0.30 input, $0.03 cached, $2.50 output). Test the new model first.
  • If you rely on gpt-5.6-sol, plan for November 30. Its promotional price runs through that date and OpenAI has not published what it costs afterward.
  • If you still use Moonshot's K2 models, plan the move to kimi-k3.1-pro by December 1. New accounts cannot use K2, and Moonshot expects to retire it in late December.
  • If you use fast mode on claude-opus-4-8, those requests will return an error after November 30. Move fast-mode work to claude-opus-5-5, or drop the fast setting.
