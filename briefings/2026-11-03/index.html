Daily Model Brief, November 3, 2026

No vendor changed a standard list price on a tracked model since Monday, and no new public model launched. Anthropic added message threads to its API in beta with no change to pricing, and StepFun starts billing its StepAudio 3 voice models on Sunday.

Tuesday, November 3, 2026 · Prices as of 8:55 AM CT · Covers Monday, November 2 through this morning

Download PDF Subscribe

Executive Summary

No vendor I track changed a standard list token price on a publicly available model since Monday's brief, and no new publicly available model launched.

Anthropic released message threads in beta on Monday, November 2. The Messages API can now keep a conversation on the server, so each later request sends only the new messages, and a thread expires 5 minutes after its last request. Anthropic says threads do not change pricing or rate limits.

Dates coming up: StepFun starts billing its StepAudio 3 voice models at 10:00 AM CT on Sunday, November 8, and raises some older voice model prices at the same time. Google shuts down several preview speech and live audio models on Tuesday, November 17, and Microsoft retires Llama 4 Maverick on Azure on Thursday, November 19.

DeepSeek's billing for Search and Fetch calls made through DeepSeek Harness, Claude Code and Codex was set to start at 11:00 AM CT on Saturday, October 31, at $0.75 per 1,000 successful requests each; DeepSeek still lists that price and start date this morning. Moonshot's notice that K2 models are closed to accounts registered from October 31 is unchanged, and it still gives no retirement date more exact than the end of December.

Items from Monday's brief still stand: Mistral Medium 3.5 (mistral-medium-3-5) and Mistral Large 3 (mistral-large-2512) retire on Friday, April 30, 2027; OpenAI's limited-access GPT-6 Rosalind and GPT-6 Astra for Law are listed at the same prices; OpenAI's 10% uplift on FedRAMP endpoints continues; and fast mode for Claude Opus 4.8 is removed on Monday, November 30.

Not confirmed today: Amazon, ByteDance and Tencent prices, Moonshot's per-search web search prices, IBM's model list, and Microsoft, which lists no pay-as-you-go prices. Their last confirmed prices stand. Performance scores in the chart are still as of October 16 and have not been refreshed since.

What This Means for Customers

  • If you run long agent loops on Claude's Messages API, test message threads: later requests send only the new messages, and Anthropic says prices do not change. A thread expires 5 minutes after its last request and is not eligible for zero data retention, so keep the full history on your side as a fallback.
  • If you build on StepFun's StepAudio 3 voice models, the free period ends at 10:00 AM CT on Sunday, November 8. Realtime speech then bills at $0.125 per session minute, and any partial minute bills as a full minute.
  • If you still call gemini-3.1-flash-tts-preview or the preview live audio models, move to gemini-3.8-flash-tts or gemini-3.8-live before Tuesday, November 17.
  • If your agents search the web through DeepSeek Harness, Claude Code or Codex, those Search and Fetch calls are billable at $0.75 per 1,000 successful requests each. Check this week's invoice for the new line and keep it in a budget separate from token spend.
  • If you start a new project on a new Moonshot account, start on kimi-k3.1-pro: K2 models are closed to accounts registered from October 31. Existing accounts keep K2 until retirement, which Moonshot dates only as the end of December, so plan the move by December 1.
  • If you use fast mode on claude-opus-4-8, those requests will return an error after November 30. Move fast-mode work to claude-opus-5-5, or drop the fast setting.
  • If you still call mistral-medium-3-5 or mistral-large-2512, they keep working until April 30, 2027. Test mistral-large-4 now: at $0.70 input and $2.10 output per million tokens, it costs less than Medium 3.5's last listed price ($1.50 and $7.50) but more than Large 3's ($0.50 and $1.50).
  • Claude Haiku 4.5 is still active. Anthropic lists its retirement as not sooner than October 15, 2026, a date that has passed, and still sets no date. Keep a tested fallback ready.
