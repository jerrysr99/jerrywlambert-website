28 Ways AI Gets Billed: The Full List

I track 106 priced models from 18 vendors. Across them I count 28 distinct ways a vendor turns usage into a charge. Two are close to universal. Everything else is a twist on those two meters, and the twists are where budgets break. Here is the full list, most common first.

  1. Per Input and Output Token. The vendor prices input and output tokens separately, per million. Every tracked model uses it.
  2. Cached Input Read Discount. When a request reuses a prompt prefix the vendor already holds in cache, those tokens bill at a cache-hit price below the normal input price.
  3. Per-Call Server Tool Fees. When the vendor runs a tool on its own servers, such as web search, it charges per call or per 1,000 calls.
  4. Separate Cache Write Charge. The vendor bills the cache write as its own line, separate from cached reads.
  5. Batch Discount. You submit work asynchronously and accept a delay, typically up to 24 hours. Batch cuts the price in half on 39 tracked models.
  6. Free Tiers and $0 Price Lines. The vendor prices a model, a unit or a usage band at zero, either permanently or for a limited time.
  7. Speed, Priority and "Highspeed" Tiers. You pay more for faster output or for priority admission. OpenAI Ultrafast reaches 6x standard.
  8. Container and Session Runtime Fees. The vendor charges by time for a sandbox or an agent session, separately from tokens.
  9. Data Residency and Regional Price Lists. The vendor adds a surcharge to keep processing inside a named geography, or publishes a separate price list for each region.
  10. Prompt-Size (Long Context) Bands. When the prompt crosses a threshold, the whole request reprices at a higher band. 22 tracked models do this.
  11. Cache Write Priced by Retention Time (TTL). The longer the vendor holds the cache, the more the write costs.
  12. Flex (Slow, Cheap Synchronous) Tier. The request stays synchronous but accepts slower or interruptible service in exchange for a batch-like discount.
  13. Hidden Token Overhead. These are tokens you pay for but did not write: tool system prompts, tool definitions, tokenizer changes and fixed blocks.
  14. Reasoning (Thinking) Tokens Billed as Output. Internal reasoning tokens bill at the output price, even when the vendor hides or encrypts them.
  15. Cache and File Storage by Time. The vendor charges to keep data available, priced per token-hour or per GB-day.
  16. Promotional Pricing and Dated Step-Ups. The vendor publishes a price with an announced end date, or schedules an increase in advance.
  17. Time-of-Day and Day-of-Week Bands. The same model costs different amounts depending on when the request runs.
  18. Legacy Model Names Billed as a Different Model. An old model name keeps working, but a different model serves the request and sets the bill.
  19. Per Image, Per Second, Per Minute, Per Character. The vendor prices media outside the token meter, or converts each asset into a fixed number of tokens.
  20. Fine-Tuning, Training and Fine-Tuned Inference. The vendor charges for training, then charges a higher inference price for the customized model.
  21. Subscription With Bundled, Rationed Usage. The customer pays a flat monthly fee that includes usage measured in opaque limits instead of tokens.
  22. Per-User License and Bring-Your-Own-Key Fees. The customer pays a fixed fee per user, or pays a platform fee when it supplies its own vendor API key (bring your own key, or BYOK).
  23. Minimums, Top-Ups and Expiring Prepaid Balances. Vendors set spend floors, require unlock payments and let prepaid balances lapse.
  24. Commits, Take-or-Pay and Negotiated Volume Discounts. The customer promises to spend a set amount in return for a lower price, and the vendor still bills any unused commitment.
  25. Marketplace Consumption Units. The vendor prices usage in dollars, then converts it into the marketplace's own billing unit.
  26. Data-for-Discount Tiers. The vendor lowers the price in exchange for the right to use your data.
  27. Billing-Event Rules. These rules decide which events are billable, separate from the price itself.
  28. Resale Markup and Reseller Chains. A reseller prices on top of vendor cost, and resellers can sit under other resellers.
