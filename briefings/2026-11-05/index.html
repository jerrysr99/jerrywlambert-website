Daily Model Brief, November 5, 2026

No vendor changed a standard list price on a tracked model since Wednesday. OpenAI published two new image models, GPT-Image-2.6 Sunburst and Flare, and the near-term calendar (StepAudio billing Sunday, Gemini 2.5 auto-route December 1) is unchanged.

Executive Summary

No vendor I track changed a standard list token price on a publicly available text or chat model since Wednesday's brief.

OpenAI listed two new image models, GPT-Image-2.6 Sunburst (gpt-image-2.6-sunburst) and GPT-Image-2.6 Flare (gpt-image-2.6-flare). Image tokens are $8.00 input, $30.00 output and $2.00 cached per million; text tokens are $5.00 input and $1.25 cached per million, with no separate text output price listed. These are image models, not a change to any tracked chat list price.

Tencent still lists Hy4 (hy4) as a production model next to Hy4 Preview. Tencent's documentation shows the same list price as the preview, $0.834 input, $0.042 cached and $2.501 output per million tokens, and bills Hy4 at 50% of list through the end of December 31, 2026, Beijing time (9:59 AM CT on Thursday, December 31). Tencent does not say when the discount started or whether it covers the preview, and its main price list could not be confirmed today.

Google deprecated Gemini 2.5 Pro (gemini-2.5-pro) and Gemini 2.5 Flash (gemini-2.5-flash) in a Monday, November 2 notice. From Tuesday, December 1, API requests to gemini-2.5-pro route automatically to gemini-3.8-flash and requests to gemini-2.5-flash route to gemini-3.5-flash-lite, each billed at the new model's rates. Neither can be selected in Google AI Studio any longer, and gemini-2.5-flash-lite is not affected.

Moonshot still has kimi-k2.7-code, kimi-k2.7-code-highspeed and kimi-k2.6 on its deprecated list. They are closed to newly registered accounts, and retirement is expected in late December 2026, still with no exact date.

DeepSeek's Search and Fetch APIs still bill at $0.75 per 1,000 successful requests, including Search and Fetch calls made through DeepSeek Harness, Claude Code and Codex.

Dates coming up: StepFun starts billing its StepAudio 3 voice models at 10:00 AM CT on Sunday, November 8. Google shuts down several preview speech and live audio models on Tuesday, November 17, Microsoft retires Llama 4 Maverick on Azure on Thursday, November 19, and fast mode for Claude Opus 4.8 is removed on Monday, November 30.

Items from earlier briefs still stand: Anthropic's message threads beta, which Anthropic says does not change pricing; Mistral Medium 3.5 (mistral-medium-3-5) and Mistral Large 3 (mistral-large-2512) retire on Friday, April 30, 2027; OpenAI's limited-access GPT-6 Rosalind and GPT-6 Astra for Law are listed at the same prices; and OpenAI's 10% uplift on FedRAMP endpoints continues.

Not confirmed today: Amazon, ByteDance and Tencent prices, Moonshot's per-search web search prices, IBM's model list, and Microsoft, which lists no pay-as-you-go prices. Their last confirmed prices stand. Performance scores in the chart are still as of October 16 and have not been refreshed since.

What This Means for Customers

  • If you call gemini-2.5-pro, test gemini-3.8-flash before Tuesday, December 1, and review Google's breaking API changes for it. At today's list prices the routed requests cost less per token ($0.75 input and $3.75 output through December 31, against 2.5 Pro's $1.25 and $10.00 for prompts up to 200K tokens), but 3.8 Flash rises to $1.50 and $7.50 on January 1, 2027.
  • If you call gemini-2.5-flash, requests move to gemini-3.5-flash-lite on December 1 at the same text list price ($0.30 input, $0.03 cached, $2.50 output). Test the new model first.
  • If you are trying Tencent Hy4, usage through December 31 bills at half of list price. Tencent gives no start date for the discount, so check that it appears on your bill.
  • If you build on StepFun's StepAudio 3 voice models, the free period ends at 10:00 AM CT on Sunday, November 8. Realtime speech then bills at $0.125 per session minute, and any partial minute bills as a full minute.
  • If you still call gemini-3.1-flash-tts-preview or the preview live audio models, move to gemini-3.8-flash-tts or gemini-3.8-live before Tuesday, November 17.
  • If your agents search the web through DeepSeek Harness, Claude Code or Codex, those Search and Fetch calls bill at $0.75 per 1,000 successful requests each. Keep them in a budget separate from token spend.
  • If you still use Moonshot's K2 models, plan the move to kimi-k3.1-pro by December 1. New accounts cannot use K2, and Moonshot expects to retire it in late December without an exact date yet.
  • If you use fast mode on claude-opus-4-8, those requests will return an error after November 30. Move fast-mode work to claude-opus-5-5, or drop the fast setting.
  • If you still call mistral-medium-3-5 or mistral-large-2512, they keep working until April 30, 2027. Test mistral-large-4 now at $0.70 input and $2.10 output per million tokens.
