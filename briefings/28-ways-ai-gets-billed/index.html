28 Ways AI Gets Billed: The Full List

Every pricing mechanism I can document across 106 models from 18 vendors, ranked from most common to most obscure, with what to watch, how to optimize and what to avoid for each one.

Executive Summary

I track 106 priced models from 18 vendors. Across them I count 28 distinct ways a vendor turns usage into a charge. Two are close to universal. Every model prices input and output tokens, and 93 of the 106 discount cached input. Everything else is a twist on those two meters, and the twists are where budgets break.

The common twists change the price of the same token. A cache write costs 1.25x input on Anthropic, the same as input at most vendors, and nothing at all on 26 paid models. Batch cuts the price in half on 39 tracked models. Speed tiers push it the other way. OpenAI Fast is 2x standard, Anthropic fast mode takes Claude Opus 5.5 from $4/$20 to $8/$40, and OpenAI Ultrafast reaches 6x. On 22 models a prompt-size band reprices the whole request once the prompt crosses a line: above 272,000 tokens on OpenAI, at 200,000 on xAI and Gemini 2.5 Pro, above 100,000 on Claude Haiku 5.5. Data residency adds 10 percent at Anthropic and OpenAI, and on Claude served through regional Amazon Bedrock and Google Cloud endpoints.

The less common twists add new meters. Web search costs $10 per 1,000 calls at Anthropic and OpenAI. Z.ai and MiniMax charge $0.01 per call, which works out to the same price. Google charges $14 per 1,000 after 5,000 free requests a month. Code containers bill by the container-hour or by the 20-minute session. Gemini charges $0.50 per million tokens per hour to keep an explicit cache alive. DeepSeek halves its prices outside two weekday UTC windows and treats every Chinese public holiday as off-peak. Prices also move on a calendar. Gemini 4 Argon doubles on December 1, 2026, and three Gemini Flash models double on January 1, 2027. Claude 4.7 and later use a tokenizer that produces about 30 percent more tokens for the same text, which raises the bill without touching the price.

At the far end sit mechanisms that never show up as a token price. Claude Pro and Max ration usage in five-hour windows, and Claude Duet, which runs only on Opus 5.5, draws on those same plan limits. Claude Enterprise charges $20 per user per month plus API rates. OpenRouter takes 5 percent when you bring your own key. Enterprise contracts add take-or-pay commits, and some vendors sell prepaid points that expire.

My operating rule is simple. Every mechanism needs a meter, a dated price and a stacking rule. If a billing system cannot meter a mechanism, it should refuse the request that triggers it instead of billing it at the wrong price. Bill a 1-hour cache write on Moonshot Kimi K3.1 Pro at the 5-minute price and you collect $2.00 of the $4.00 owed on that line. Let a web search through unmetered and you lose $10 for every 1,000 calls.

How I Counted

I counted prevalence against my live Tariff as read on October 24, 2026: 106 priced models from 18 vendors (Alibaba, Amazon, Anthropic, Cohere, DeepSeek, Google, Meta, Microsoft, MiniMax, Mistral, Moonshot, OpenAI, StepFun, Tencent, TypeSafe, Xiaomi, xAI, Z.ai). [T1]

For mechanisms my Tariff stores directly (token prices, cache prices, prompt-size bands, peak and off-peak bands, $0 lines, scheduled step-ups, per-request fees), the count is the number of tracked models that carry the mechanism. For mechanisms vendors publish but my Tariff does not store as a separate line (batch, speed tiers, web search, data residency, storage, runtime), the count is the number of the 106 models whose vendor's own pricing page offers it. I mark those counts "exposed."

Mechanisms outside per-model API pricing (subscriptions, per-user licenses, commits) count 0 tracked API models and sit at the end, ordered by how many vendors use them. The ranking measures how many tracked models can produce a charge, not how often the charge appears on invoices. The 106 models are the set I track, not the whole market.

Prices are US dollars per million tokens unless stated. A pair such as $4/$20 means $4 per million input tokens and $20 per million output tokens. Tags such as [A1] point to the Sources and Methodology appendix. Any claim I could not confirm against a vendor's own page or my live Tariff carries the label UNVERIFIED.

Name · Mechanism 1 of 28

Per Input and Output Token

106 of 106 models
Description

This is the base meter. The vendor prices input (prompt) tokens and output (completion) tokens separately, per million. Output almost always costs more.

Example

Claude Opus 5.5 lists $4.00 input and $20.00 output. [T1][A1] Across the 106 models I track, input runs from $0.03 (Z.ai GLM-OCR) to $30.00 (OpenAI gpt-5.5-pro), and output tops out at $180.00, also on gpt-5.5-pro. [T1][O1] The output-to-input ratio clusters at a few values. [T1]

Output-to-input ratioTracked models
5x26
4x17
6x11
3x10
Models That Use It

All 106 tracked models from all 18 vendors. [T1]

Things to Watch

  • Output-heavy work such as agents, code generation and long reports is priced on the expensive side. At a 5x ratio, one output token costs as much as five input tokens.
  • Token counts do not compare cleanly across vendors, or even across generations of one vendor's models (see Mechanism 13).
  • Some vendors price output at $0. TypeSafe Jev bills $0.042 input and $0 output. [T1][TS1]

Ways to Optimize

  • Cap output length with a max-tokens setting and ask for structured, terse output.
  • Route by task. Claude Haiku 5.5 at $0.10/$0.50 against Opus 5.5 at $4/$20 is a 40x spread inside one vendor. [A1]

Things to Avoid

  • Comparing models on input price alone.
  • Treating a list price as the effective price. Nearly every mechanism that follows changes it.

Cached Input Read Discount

93 of 106 models
Description

When a request reuses a prompt prefix the vendor already holds in cache, those tokens bill at a cache-hit price below the normal input price.

Example
Vendor and modelCache read priceSource
Anthropic, most models0.1x inputA1
Anthropic Opus 5.5 and Sonnet 5.50.05x inputA1
Anthropic Fable 5.10.025x input ($0.25 against $10.00)A1
DeepSeek Flash, off-peak$0.003 cached against $0.15 uncached (98 percent off)D1

Across tracked models the most common ratio is 0.1x (37 models), then 0.2x (11 models) and 0.25x (9 models). [T1]

Models That Use It

93 of 106 models across 17 vendors. TypeSafe is the exception. Five models price a cache read at the full input price (three Alibaba models, plus OpenAI gpt-5.5-pro and o3-pro). Six paid models publish no cache price at all (four TypeSafe models, two Z.ai models). The last two are Google Gemma 4 12B and 31B, which carry all four price lines (input, output, cache read and cache write) at $0. That makes 93 + 5 + 6 + 2 = 106. [T1][O1][Z1][G1]

Things to Watch

  • Discounts vary 30-fold, from 0.0083x (Xiaomi MiMo-V2.6-Pro) to 0.25x. Only 37 of the 93 discounting models (40 percent) charge exactly 0.1x. A blanket "90 percent off cached input" assumption is wrong for the other 56 (60 percent), and for 69 of all 106 tracked models (65 percent) once you add the at-par, unpriced and free models.
  • On Anthropic, a cache hit also refreshes the cache timer. [A1]
  • Some models cache only implicitly. Google says Gemini 4 Argon supports "implicit caching only (explicit caching is not supported)." [G1]

Ways to Optimize

  • Put stable content first (system prompt, tool definitions, reference documents) and variable content last, so the prefix matches.
  • Keep a conversation on one model. Caches do not carry across models.

Things to Avoid

  • Reordering tools or injecting a timestamp at the top of the prompt. Either one breaks the prefix.
  • Billing a model with no published cache price as if it had one. A cache price with no first-party basis is an invented number.

  • The fee is per call, not per answer. One prompt can fan out into many searches.
  • The tool's results come back as input tokens and stay in context on later turns. [A1]

  • Cap tool calls per request.
  • Prefer token-only tools where the vendor offers them, such as Anthropic web fetch and Google URL context. [A1][G1]

Things to Avoid

  • Letting a server tool through a billing layer that cannot count it. If the call count is not metered, refuse the tool instead of billing tokens only.

Free Tiers and $0 Price Lines

30 models
Description

The vendor prices a model, a unit or a usage band at zero, either permanently or for a limited time.

Example
  • Fully free models. Google Gemma 4 is free tier only and listed as "Not available" on paid. I track two sizes, 12B and 31B. Z.ai also lists GLM-4.7-Flash, GLM-4.5-Flash and GLM-4.6V-Flash as free, but I do not track those three. [G1][Z1][T1]
  • Free units. TypeSafe Jev output is $0. Amazon Nova cache writes are $0. Z.ai and Xiaomi cache writes are free for a limited time. [T1][TS1][Z1][X1]
  • Free allowances. Anthropic code execution includes 1,550 free hours per organization per month. Google grounding includes 5,000 requests per month. OpenAI includes 1 GB of file storage, and OpenAI moderation is free. [A1][G1][O1]
  • Free trial credit. Anthropic gives new users "a small amount of free credits." [A1]
Models That Use It

30 of 106 models carry at least one $0 price line: Z.ai 18, TypeSafe 4, Amazon 3, Xiaomi 3, Google 2. Two tracked models are entirely free: Gemma 4 12B and Gemma 4 31B. Z.ai's three free Flash models are on the vendor's list but not among the 106 I track. [T1][Z1]

Things to Watch

  • A free tier can carry a data cost. Google's free tier states "Content used to improve our products." [G1]
  • A $0 line with no first-party source looks exactly like a missing price.

Ways to Optimize

  • Use free allowances for development and evaluation traffic.

Things to Avoid

  • Recording an unknown price as $0. A $0 line should carry its source and the vendor's own word "free."

Data Residency and Regional Price Lists

23 exposed models
Description

The vendor adds a surcharge to keep processing inside a named geography, or publishes a separate price list for each region.

Example
  • Anthropic's inference_geo: "us" setting is 1.1x on every token category for Claude 4.6 and later. [A1]
  • Claude on Amazon Bedrock regional endpoints and Google Cloud multi-region endpoints carries a 10 percent premium over global endpoints. [A1]

Models That Use It

23 exposed models: 11 Claude models with US-only inference, plus 12 models priced from a region-specific list (Alibaba 7, Xiaomi 3, Tencent 2). Which OpenAI models carry the uplift depends on each model's release date, and that count is UNVERIFIED. [A1][T1]

Things to Watch

  • The surcharge multiplies every other mechanism, including fast mode and long-context bands. [A1]

Ways to Optimize

  • Use residency only for data that requires it, and route the rest globally.

Things to Avoid

  • Accepting a residency parameter on a route that bills global rates.

Hidden Token Overhead

13 exposed models
Description

These are tokens you pay for but did not write: tool system prompts, tool definitions, tokenizer changes and fixed blocks.

Example
  • Anthropic adds a tool-use system prompt of 286 tokens (Opus 5.5) to 675 tokens (Opus 4.7) whenever tools are present. The computer-use toolset adds about 4,500 input tokens and the browser toolset about 6,600. [A1]
  • Claude 4.7 and later use a tokenizer that "produces approximately 30% more tokens for the same text." [A1]
  • OpenAI bills web search content for gpt-4o-mini and gpt-4.1-mini as a fixed block of 8,000 input tokens per call. [O1]
Models That Use It

13 exposed models. All 12 tracked Claude models carry tool overhead, and 9 of them also use the newer tokenizer. The thirteenth is OpenAI gpt-4.1-mini, under the fixed 8,000-token search block. The other model named in that OpenAI rule, gpt-4o-mini, is not one I track. [A1][O1][T1]

Things to Watch

  • A model with a lower list price can cost more per task if it emits 30 percent more tokens.

Ways to Optimize

  • Compare models on cost per completed task, not cost per token.
  • Declare only the tools a request needs.

Things to Avoid

  • Carrying old per-token benchmarks across a tokenizer change.

How the Mechanisms Stack

Vendors publish how their multipliers combine. On Anthropic, cache multipliers stack on fast mode, data residency stacks on fast mode, batch and caching combine, and fast mode is not available with batch. [A1]

Anthropic's own worked example: a one-hour Managed Agents session on Opus 5.5 with 50,000 input tokens and 15,000 output tokens costs $0.58 ($0.20 input, $0.30 output, $0.08 runtime). If 40,000 of those input tokens are cache reads, the session costs $0.428. [A1]

The order I use for a billing system: select the prompt-size band, apply multipliers (speed, residency), apply resale rules, then volume tiers and discounts, then credits, then draw down any commit. [B1]
