Daily Model Brief, October 30, 2026

Mistral cut the list price of Mistral Large 4 by about half on Thursday, the only token price change since Thursday's brief. Tomorrow, DeepSeek starts billing Search and Fetch and Moonshot closes K2 to new accounts. Moonshot's Batch API now covers K3 and K3.1 Pro.

Friday, October 30, 2026 · Prices as of 8:47 AM CT · Covers Thursday, October 29 through this morning

Executive Summary

Mistral cut the list price of mistral-large-4 by about half on Thursday, October 29, after Thursday's brief went out. Input fell from $1.36 to $0.70, cached input from $0.14 to $0.07 and output from $4.18 to $2.10 per million tokens. Mistral shows no sale marker or end date, so this is the new list price.

Both Saturday changes take effect tomorrow, October 31, and I re-checked them this morning. At 11:00 AM CT, DeepSeek starts billing Search and Fetch calls made through DeepSeek Harness, Claude Code and Codex at $0.75 per 1,000 successful requests each, a dollar price DeepSeek confirms today. The same day, Moonshot stops letting newly registered accounts use its K2 models, and it still gives no exact retirement date beyond the end of December.

Moonshot's Batch API now covers kimi-k3.1-pro and kimi-k3; before, it covered only the K2 models. Batch pricing stays at 60% of standard rates, and batch jobs on these two models also pay cache-write fees.

Google made its Computer Use tool generally available on Friday, October 30. It carries no separate fee: it is charged as regular tokens at the model's price.

No other vendor I track changed a token price or launched a new model since Thursday's brief: Anthropic, OpenAI, Google, xAI (Grok), DeepSeek, Moonshot, Z.ai, MiniMax, Alibaba, Cohere, Meta, TypeSafe, Xiaomi, StepFun and Perplexity. gpt-6.1-terra still costs $1.00 input, $0.05 cached and $5.00 output per million tokens, half of gpt-6.1-sol.

Not confirmed today: Amazon and ByteDance prices, Tencent prices (last confirmed Thursday afternoon, October 29), Moonshot's per-search web search prices, IBM's model list, and Microsoft, which lists no pay-as-you-go prices. Their last confirmed prices stand. Performance scores in the chart are still as of October 16 and have not been refreshed since.

What This Means for Customers

  • If you use mistral-large-4, your token cost roughly halves from Thursday, October 29, with nothing to change on your side. If you ruled it out on price, re-run the comparison at $0.70 input and $2.10 output per million tokens.
  • If your agents search the web through DeepSeek Harness, Claude Code or Codex, DeepSeek starts billing those Search and Fetch calls at 11:00 AM CT tomorrow, Saturday, October 31, at $0.75 per 1,000 successful requests each. Set a budget line for it today, separate from token spend.
  • If you run kimi-k2.6 or kimi-k2.7-code, any Moonshot account registered from tomorrow cannot use K2, so new projects on new accounts should start on kimi-k3.1-pro. Existing accounts keep access until retirement, which Moonshot still dates only as the end of December.
  • If you run large offline jobs on kimi-k3.1-pro or kimi-k3, the Batch API now bills them at 60% of standard rates. Budget for the cache-write fees batch jobs on these models still pay, and expect cache hits only on a best-effort basis.
  • If your app grounds Gemini answers with Google Search, check your daily peak against the 1,500-request daily cap Google lists, and spread large batch jobs across days if you are near it. The cost per search is unchanged.
  • If you use gpt-6.1-sol, test gpt-6.1-terra on the same work: every token price is half. Check output quality first, and check prompt sizes, because a request over 272,000 input tokens bills entirely at the higher long-context rate.
  • If you still run gpt-4.1 or gpt-4.1-mini, shutdown is January 14, 2027, and the replacement is gpt-6-luna.
  • Claude Haiku 4.5 is still active. Anthropic lists its retirement as not sooner than October 15, 2026, a date that has passed, and still sets no date. Keep a tested fallback ready.
